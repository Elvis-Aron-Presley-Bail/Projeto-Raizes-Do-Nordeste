# Projeto-Raizes-Do-Nordeste
Este projeto foi desenvolvido como parte de um trabalho acadêmico proposto pela faculdade Uninter, no curso de Análise e Desenvolvimento de Sistemas (ADS), que estou cursando.

# Introdução
O projeto Raízes do Nordeste é um cardápio digital que simula pedidos online. Ele possui 3 unidades em Curitiba: Pinheirinho, Capão Raso e Sítio Cercado.

# Funcionalidades
Simulação de Cadastro: Opção de 'criar conta' e 'login', com e-mail para teste (teste123@gmail.com) e senha (Senha123).

Conformidade LGPD: É necessário marcar a caixinha de conformidade LGPD para poder realizar o Login/Criar Conta.

Promoção do dia: Exibe o combo de uma comida, uma bebida e uma sobremesa. Cada bairro tem seu próprio combo.

Carrinho de compras: Lista os produtos e tem a opção remover item. Também, ao trocar de bairro, o carrinho se limpa automaticamente.

Pagamento por PIX: Ao selecionar a opção pagar com o PIX, uma caixa escrito QR CODE aparece.

Pagamento por Cartão: Aparece as opções de cartão para preencher.

Pagamento por Dinheiro: 
Exibe um campo de solicitação de troco.

Programa de Fidelidade: 
Para cada R$100,00 em compras, você ganha um cupom de 10% de desconto para a próxima compra.

Acompanhamento do Pedido: 
Se você escolheu 'retirar no balcão', ele exibe um acompanhamento diferente caso você tivesse escolhido a opção 'entrega em casa'.

# Organização dos Arquivos: 
Uma pasta para HTML, uma pasta para CSS e uma pasta para JavaScript.

# Tecnologias Utilizadas: 
HTML, CSS e JavaScript.
